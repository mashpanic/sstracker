# Monster Train 2 Run Tracker

A run tracker for Monster Train 2.
This tracker only covers Soul Savior Mode at Overgrowth difficulty.

Use it at https://mashpanic.github.io/sstracker/ (your entries are saved in your browser).
The app is in `web/` and runs from plain files: open `web/index.html` to use it offline.
