How to use this app

This tracker has four screens, switched with the buttons at the bottom of each screen:

  • Run Tracker — plan and follow a Soul Savior run.
  • Win-Loss — keep a win/loss tally per starting champion.
  • Souls — A reference list.
  • Help — this page.
  • Import/Export — your win-loss data, later on this page.

Quick Start

Set Region Bosses with single keystrokes at the beginning of a run. For example, press S (tab) C (tab) D (tab) V (tab) C to select Stern Sister, Train Chomper, Duplicitous, Energy Vampire, and Corpseflower. Use the first letter of the last word of the boss name, except for Maera (E-Eldest, H-Hierarchy, S-Stern Sister).

After the Astrael battle, quickly set the Central Nodes using the keyboard. Enter sets such as Magic, Trinkets, Boons by hitting M (tab) T (tab) B (tab).

View a row's enemy waves in the bottom box by highlighting it. Make sure its Boss Variant, Wave Set, and Region Order are all selected for full information — Region Order will temporarily set to the next Order to allow easy comparison of routes.

Run Tracker

  • Order — set each mid-run region's combat order (1–4) in its Order box. A number you pick is greyed out for the other regions, and the rows re-sort into that order.
  • Variant — for each encounter, pick its boss / wave-set Variant.
  • Central Nodes — select Central Nodes from the dropdown, or focus a box and press the first letter of a choice.
  • Wave box — click a Battle or Boss row to see its waves. You must select the enemy wave set if required. If no order is selected, a preview of the next unselected Order will show. You must still manually set that order.
  • Reset grid — clears every selection for the current run (it asks first). It does not affect your Win-Loss record.

Win-Loss

  • Tiles — each champion is a card-art tile showing its record as wins-losses (e.g. "7-3") at the bottom right.
  • Select — click a tile to select it (white outline). One champion is always selected; Fel is selected by default.
  • Adjust — the bottom bar shows the selected champion's name and record. W+ / W− / L+ / L− change its record (counts never go below 0).
  • Streak — Add to streak puts the selected champion in the current streak (green border); click it again (it reads "In streak ✓") to take it out. The bar shows how many champions are in the streak. Wins and losses are separate from the streak, so W+ / L+ never change it.
  • Reset streak — clears the streak for a new one but keeps every win/loss count (it asks first).
  • Reset record — clears all win/loss counts but keeps the streak (it asks first). It does not affect the Run Tracker.

Everything you enter is saved in your browser and restored when you come back.

Backup & transfer

Your data lives only in this browser. Use these to move your Win-Loss record to another browser or device, or to keep a backup. The export is a plain-text JSON file. The Run Tracker is not included — it's for a single run and isn't meant to carry over, and importing never touches an in-progress run.

  • Export data — shows your Win-Loss record as JSON text you can copy or download as a file.
  • Import data — paste that text (or pick a downloaded file) to load it. It replaces your Win-Loss record, then reloads the page.
